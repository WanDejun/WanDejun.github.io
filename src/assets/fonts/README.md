# Bundled Fallback Fonts

`SymbolsNerdFont-Regular.woff2` is converted from Symbols Nerd Font 3.4.0 and
provides Nerd Font and Powerline private-use glyphs. Its upstream project is
<https://github.com/ryanoasis/nerd-fonts> and its license is included in
`LICENSE-nerd-fonts.txt`.

`NotoColorEmoji-Regular.woff2` is converted from the no-flags COLRv1 build of
Google Noto Emoji. System color Emoji fonts remain preferred when available.
Its upstream project is <https://github.com/googlefonts/noto-emoji> and its
license is included in `LICENSE-noto.txt`.
