# Neko Terminal Homepage

This project turns a personal homepage into a read-only, Linux-inspired shell.
The virtual filesystem keeps posts, project notes, and standalone slide decks in
one content tree while xterm.js provides the interactive terminal surface.

## Design goals

- Keep published content independent from the React application code.
- Make familiar shell commands useful for browsing and reading.
- Render rich Markdown without hiding its plain-text source.
- Open standalone HTML presentations without navigating away from the terminal.

Project articles can be added beside this file and organized in nested folders.
