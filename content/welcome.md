# Welcome to Neko Terminal

This site is a small, read-only terminal you can explore with familiar Linux commands.

- Run `help` to see the available commands and usage examples.
- Browse the archive with `tree /posts` or `find /posts -type f`.
- Render a post with `render /posts/path/to/post.md`.
- Open an HTML presentation with `render /slide/example/index.html`.
